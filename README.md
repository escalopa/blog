# [escalopa.com](https://escalopa.com)

Ahmed Helaly's engineering blog, built with Hugo and the Blowfish theme.

## Engineering library

The resume-aligned engineering library is generated from a reviewed catalog.
Every generated post contains a `.generated` marker and can be rebuilt with:

```bash
python3 scripts/generate_engineering_library.py
```

The generator creates 100 Markdown page bundles and deterministic SVG covers
across six series: Production Go, Distributed Systems, Backend APIs, Data
Systems, Reliable Platforms, and Architecture Practice.
